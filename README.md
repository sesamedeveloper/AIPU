# How I Worked

1. Created the sample HTML and CSS files and placed them in the appropriate folders.

2. Added the client logos to the `images/client` folder for display in the client banner. The banner structure was already included in the default code.

3. Created a folder named `Content`.

4. Added the following files to the `Content` folder:
   - `MERN AIPU LP contents .docx` – Contains the MERN AIPU landing page content.
   - `Style.txt` – Contains the preferred theme and CSS styling guidelines.

   **Note:** The style reference (`Style.txt`) was created with ChatGPT using a sample page image from `MERN LP Draft.pdf` (Sample_Image.png).

5. Updated the existing HTML and CSS files based on the content in `MERN AIPU LP contents .docx` and the styling guidelines in the `Style.txt` file.

6. Used `Prompt.txt` to guide the HTML and CSS modifications.

   The prompt references two skills that are installed by default:
   - **Caveman** – Helps generate concise and direct content.
   - **UI UX Pro Max** – Helps improve UI/UX design and styling.
